Sistema de Gestión de Ventas e Inventario para Tienda

En este archivo se encuentra mi proyecto desarrollado en C++ como parte del proyecto final del curso de programación. El sistema permite administrar productos, controlar inventario, registrar ventas y generar reportes utilizando archivos binarios para mantener la información almacenada entre ejecuciones.

## Funcionalidades

* Registro y administración de productos.
* Búsqueda por código y nombre.
* Actualización de precios y stock.
* Registro de ventas con IVA y descuentos automáticos.
* Reportes de inventario y ventas.
* Exportación de reportes a archivo de texto.
* Estadísticas generales del sistema.

## Tecnologías Utilizadas

* Lenguaje C++
* Programación estructurada
* Archivos binarios (.dat)
* Arreglos y matrices
* Algoritmos de búsqueda y ordenamiento
* Manejo de excepciones

## Estructura del Proyecto

* `main.cpp` → Punto de inicio del programa.
* `interfaz.h / interfaz.cpp` → Menús e interfaz de usuario.
* `sistema.h / sistema.cpp` → Lógica principal del sistema.
* `estructuras.h` → Definición de estructuras.
* `productos.dat` → Almacenamiento de productos.
* `ventas.dat` → Almacenamiento de ventas.
